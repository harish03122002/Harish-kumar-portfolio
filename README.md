## 💻 Running the Project Locally

Because this is a pure static web project, you do not need to install `npm` packages or build tools.

### Option 1: Direct File Open
Double-click `index.html` or right-click and choose **Open with > Chrome / Edge / Firefox**.

### Option 2: Live Server (Recommended)
If you are using Visual Studio Code:
1. Install the **Live Server** extension (by Ritwick Dey).
2. Right-click `index.html` and select **"Open with Live Server"**.
3. The website will open at `http://127.0.0.1:5500/index.html`.

## 🌐 Deploying to GitHub Pages

Once pushed to GitHub, you can publish this portfolio for free:

1. Navigate to your repository on GitHub.
2. Go to **Settings** > **Pages** (under Code and automation).
3. Under **Build and deployment**:
   - Source: **Deploy from a branch**
   - Branch: **main** (or `master`), Folder: `/ (root)`
4. Click **Save**.
5. In a few moments, your portfolio will be live at:
   `https://<your-username>.github.io/<repository-name>/`
